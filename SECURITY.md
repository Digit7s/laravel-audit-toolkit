# Security policy

Please report suspected vulnerabilities privately to the Digit7s maintainers before public disclosure. Include the affected package/version, a minimal reproduction, impact, and a suggested mitigation when available. Do not include real credentials, production audit data, or personal data in a report.

The packages are development-stage open-source components. A passing test suite is not a production security certification. Authentication auditing is opt-in, audit access is host-authorized, and database users can still modify rows unless database-level controls are separately configured.
